# 验证范围

运行 `npm test`：先编译，再运行 Node 测试。全部使用临时目录和合成课程，不需要真实学校登录；Chrome DOM 测试启动本机 Chrome并拦截请求，因此需要本机 Chrome；Windows 尚未实机执行。

覆盖配置/跨学期授权、MCP工具发现与设置门槛、真实观察名单校验、清空保留历史、路径与符号链接安全、分页与隐藏课程、完整/空/延迟/部分课程结构、下载网络与解析重试、429整批停止、相对文件链接、HTML保存、内容校验和旧版本、磁盘提交错误、锁清理与错误分类。发布测试在临时Git仓库中验证白名单导出、来源记录、个人标记和脏工作区拒绝。

设置向导依赖交互终端和学校登录：保存/选择/确认的核心逻辑已通过模拟测试与MCP客户端验证；没有让新用户用真实账号完整走过首次安装、MFA和自定义目录向导。doctor及macOS入口做环境检查和shell语法校验，不等于端到端安装实测。skill通过结构检查与人工场景复核，不等于证明模型所有情况下都遵循。

维护者曾用真实专用会话下载并验证61个资源（含PDF和HTML），增量检查未新增重复版本；首次Lecture1解析失败后单独重试成功，根因未知。可靠性修复后，新版代码已只读检查真实登录与三门资源列表（文件模块3/29/29），当前页面通过发现加载检查；资源计数不等于证明发现完整。六项可靠性修复基于模拟反例测试，不通过修改学校数据或制造真实限流验证。公开包不包含这些私有课件与验证记录。

未验证：其他真实账号/学期、未来站点DOM变化、真实多层文件夹、长期会话稳定性、断电级一致性、其他MCP客户端、其他学校/OS/浏览器。课程发现完整性检查针对已知UNNC布局，不能证明未来所有插件均完整。改根目录没有自动迁移能力。遇到不支持页面应明确失败，不能猜链接或宣称通用兼容。

Windows 适配新增 LocalAppData 路径与回退、目录边界和保留文件名测试；跨盘与大小写断言仅在 Windows 执行，macOS 模拟路径不等于 Windows 文件系统实测。

Windows 验收：安装 Node.js 24+ 与 Chrome；从含空格的路径运行 setup.cmd；亲自完成学校登录/MFA；生成配置并验证标准 MCP stdio 工具发现和调用；仅选已批准课程，验证少量下载、重复同步、旧版本与用户修改保留、organize 和占用时停止；运行 npm test。符号链接测试需要开发者模式或相应权限，不应移除安全检查。记录系统/Node/Chrome 版本、源码 commit 和差异，以及 failed/skipped/停止原因。单独检查长路径与 ACL。Windows 自动升级尚未适配。

Windows 测试会明确跳过 macOS 专属自动升级的三项集成测试，以及 POSIX 可执行位测试；通用升级回滚、核心与安全检查继续执行。
